# BARLAU.KZ - Новый Фронтенд

Современный фронтенд для системы управления логистикой BARLAU.KZ, построенный с использованием стиль-системы MaroAI.

## 🚀 Технологии

- **React 18** с TypeScript
- **Vite** - быстрая сборка и разработка
- **Tailwind CSS** - утилитарные стили
- **Radix UI** - доступные компоненты
- **Lucide React** - современные иконки
- **Class Variance Authority** - система вариантов компонентов

## 🎨 Стиль-система MaroAI

Проект использует собственную стиль-систему с:
- **Основной цвет**: `#8962DB` (фиолетовый)
- **Поддержка темной темы**
- **Адаптивный дизайн**
- **Доступность** через Radix UI
- **Система вариантов** компонентов

## 📦 Установка и запуск

```bash
# Установка зависимостей
npm install

# Запуск в режиме разработки
npm run dev

# Сборка для продакшена
npm run build

# Предварительный просмотр сборки
npm run preview
```

## 🏗️ Структура проекта

```
src/
├── components/           # React компоненты
│   ├── ui/              # UI компоненты (Button, Input, Card, etc.)
│   └── LoginForm.tsx    # Форма входа
├── lib/                 # Утилиты
│   └── utils.ts         # Функция cn() для объединения классов
└── index.css           # Глобальные стили и CSS переменные
```

## 🎯 Особенности

### Форма входа
- Красивый градиентный фон
- Анимации и переходы
- Показ/скрытие пароля
- Состояние загрузки
- Валидация полей
- Адаптивный дизайн

### UI Компоненты
- **Button** - различные варианты (default, outline, ghost, etc.)
- **Input** - стилизованные поля ввода
- **Card** - карточки с заголовками и контентом

## 🔧 Настройка

### Tailwind CSS
Конфигурация находится в `tailwind.config.js` с настроенными цветами и переменными.

### TypeScript
Настроены алиасы путей:
- `@/*` → `./src/*`

### CSS переменные
Все цвета определены через CSS переменные в `src/index.css` для поддержки темной темы.

## 🌐 Доступ

После запуска проект доступен по адресу: http://localhost:5173
