# Дизайн-система BARLAU.KZ

## 🎨 Цветовая палитра

### Основные цвета
- **Акцентный цвет**: `#267BD9` (синий)
- **Цвет при наведении**: `#1e6bb8` (темнее синий)
- **Текст**: `#1f2937` (темно-серый)
- **Вторичный текст**: `#6b7280` (серый)
- **Фон**: `#f9fafb` (светло-серый)

### Применение цветов
```css
/* Основная кнопка */
background: #267BD9;
hover: #1e6bb8;

/* Ссылки и акценты */
color: #267BD9;

/* Фокус на полях ввода */
ring-color: #267BD9;
```

## 📐 Геометрия

### Радиусы закругления
- **Маленький**: `0.375rem` (6px) - мелкие элементы
- **Средний**: `0.5rem` (8px) - кнопки, поля
- **Большой**: `0.75rem` (12px) - карточки, модальные окна
- **Очень большой**: `1rem` (16px) - контейнеры

### Размеры
- **Высота полей**: `44px` (11 в Tailwind)
- **Высота кнопок**: `36px` (9 в Tailwind) / `40px` (10 в Tailwind)
- **Отступы карточек**: `24px` (6 в Tailwind)

## 🖼️ Визуальные элементы

### Логотип
- Специальный логотип BARLAU.KZ (не иконка грузовика)
- Размер на странице входа: 80x80px
- Фон логотипа: синий #267BD9

### Фоны
- **Страница входа**: фоновое изображение (не градиент)
- **Основной фон**: `#f9fafb`
- **Карточки**: белый с тенью

### Тени
```css
/* Карточки */
box-shadow: 0 1px 3px 0 rgb(0 0 0 / 0.1), 0 1px 2px -1px rgb(0 0 0 / 0.1);

/* Большие карточки */
box-shadow: 0 10px 15px -3px rgb(0 0 0 / 0.1), 0 4px 6px -4px rgb(0 0 0 / 0.1);
```

## 📱 Адаптивность

### Брейкпоинты
- **Mobile**: до 640px
- **Tablet**: 641px - 1024px  
- **Desktop**: 1025px+

### Мобильные особенности
- Увеличенные области касания (минимум 44px)
- Упрощенная навигация
- Оптимизированные формы

## 🔤 Типографика

### Шрифты
- **Основной**: system-ui, sans-serif
- **Заголовки**: жирный (font-weight: 600-700)
- **Основной текст**: обычный (font-weight: 400)

### Размеры
- **H1**: 1.875rem (30px)
- **H2**: 1.5rem (24px)  
- **H3**: 1.25rem (20px)
- **Основной текст**: 0.875rem (14px)
- **Мелкий текст**: 0.75rem (12px)

## ⚡ Анимации

### Переходы
```css
/* Стандартный переход */
transition: all 0.2s ease-in-out;

/* Кнопки */
transition: background-color 0.2s, border-color 0.2s, color 0.2s;

/* Поля ввода */
transition: border-color 0.2s, box-shadow 0.2s;
```

### Состояния загрузки
- Спиннер: белый на цветном фоне
- Размер: 16px (w-4 h-4)
- Анимация: `animate-spin`

## 📋 Компоненты

### Кнопки
- Высота: 36px или 40px
- Радиус: `rounded-lg` (12px)
- Отступы: 16px по горизонтали

### Поля ввода
- Высота: 44px
- Радиус: `rounded-lg` (12px)
- Граница: 1px серая
- Фокус: синяя обводка

### Карточки
- Радиус: `rounded-xl` (16px)
- Фон: белый
- Тень: стандартная
- Отступы: 24px

## 🎯 Принципы

1. **Консистентность** - одинаковые элементы везде выглядят одинаково
2. **Доступность** - контрастные цвета, понятная навигация
3. **Простота** - минимум визуального шума
4. **Отзывчивость** - работает на всех устройствах
