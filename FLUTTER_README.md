# Резервная копия Flutter приложения

В этом репозитории содержится код Flutter приложения BARLAU.KZ с исправлениями проблем загрузки сотрудников и кэширования.

## Исправленные проблемы

1. Исправлен URL для API: убрано двойное /api/
2. Обновлена обработка ответа API с полем 'results'
3. Реализован реальный HTTP запрос вместо демо данных
4. Улучшена совместимость между iOS и Android версиями

## Скрипты для управления эмуляторами

- restart_emulators.sh - перезапуск эмуляторов
- restart_emulators_fixed.sh - улучшенный перезапуск с диагностикой
- restart_flutter_apps.sh - перезапуск Flutter приложений с очисткой кэша
- stop_emulators.sh - остановка всех эмуляторов

## Документация

- EMPLOYEES_LOADING_FIX.md - подробное описание исправлений
- ANDROID_FIX_SUMMARY.md - сводка по исправлениям для Android
- UNIFIED_DATA_SOURCE_FINAL.md - документация по единому источнику данных
