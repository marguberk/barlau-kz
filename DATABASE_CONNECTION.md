### Настройка прав доступа
В файле `core/views.py` добавлены разрешения для GET запросов в DEBUG режиме:

```python
def get_permissions(self):
    """
    Переопределяем получение разрешений для разрешения GET запросов в DEBUG режиме
    """
    if self.request.method == 'GET' and settings.DEBUG:
        return [permissions.AllowAny()]
    return [permission() for permission in self.permission_classes]
```

## Архитектура приложения

### Приоритет подключения
1. Локальный сервер (192.168.27.223:8000)
2. Localhost (127.0.0.1:8000)
3. Продакшн сервер (85.202.192.33:8000)
4. Тестовые данные (fallback)

### Индикатор подключения
- 🟢 Зеленый: Подключено к серверу
- 🔴 Красный: Используются тестовые данные

### Обработка ошибок
- Timeout: 5 секунд для каждого endpoint
- Graceful fallback на тестовые данные
- Логирование всех попыток подключения
- Информативные сообщения пользователю

## Безопасность

### Аутентификация
- Задачи: Разрешены GET и PATCH запросы без аутентификации в DEBUG режиме
- Сотрудники: Разрешены GET запросы без аутентификации в DEBUG режиме
- Продакшн: Требуется полная аутентификация

### Данные
- Все чувствительные данные скрыты в продакшн режиме
- Тестовые данные используются только при отсутствии подключения
- Логи содержат только необходимую информацию для отладки
